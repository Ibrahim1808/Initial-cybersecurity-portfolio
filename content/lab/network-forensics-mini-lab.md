## Setup

This mini lab uses sample packet captures and a simple analysis workflow to practice finding anomalies, tracing sessions, and recording notable indicators.

## Skills reinforced

- Traffic triage
- Session reconstruction
- IOC extraction
- Concise investigative summaries

## Why include it

Labs like this communicate hands-on learning and analytical discipline, which are both valuable in a security portfolio.
