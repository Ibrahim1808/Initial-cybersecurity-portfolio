## Goal

Build a lightweight recon pipeline that helps identify API attack surface faster, especially across larger targets with many subdomains and changing deployments.

## Workflow

1. Gather target hosts
2. Probe for API signatures
3. Normalize paths and response patterns
4. Prioritize endpoints for deeper testing

## Portfolio angle

This project shows process design, offensive methodology, and the ability to turn noisy recon output into actionable targets.
